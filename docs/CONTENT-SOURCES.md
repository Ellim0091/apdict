# Content acquisition plan (checked 2026-10-17)

Start with a curated set of 16 draft concepts in `data/entries.json`, 16 questions, and 11 connections. These are original AI-assisted drafts, not imported textbook passages. The owner has not yet approved their scientific accuracy or AP alignment. Further-reading URLs are references for review, not claims that each passage has been manually checked against the linked source. The owner still needs to select a redistribution license for original project content.

## Recommended workflow

Use the College Board course outlines as the scope checklist, author concise explanations, then check them against reputable subject references. Begin with water/bonding, membranes, energy/enzymes, acids/bases and redox; add genetics and the remaining units next. Keep exam questions original rather than copying official assessments.

- AP Biology scope: https://apcentral.collegeboard.org/courses/ap-biology
- AP Chemistry scope: https://apcentral.collegeboard.org/media/pdf/ap-chemistry-course-and-exam-description.pdf

College Board material is a scope/reference source, not an assumed open-license content feed. The app has no affiliation with or endorsement by College Board.

## Biology and chemistry explanations: OpenStax

- https://openstax.org/books/biology-2e/pages/preface
- https://openstax.org/books/chemistry-2e/pages/preface

The current pages list CC BY-NC-SA 4.0. This changes the original plan's assumption that generic OpenStax copying would be straightforward CC BY reuse. Link to further reading now. Before copying/adapting passages or figures, check the specific edition/file's terms and attribution, noncommercial and share-alike obligations. Do not assume an older downloaded asset has the same license as today's web text. No OpenStax passages or figures were bulk imported.

## Chemical entities: ChEBI

- https://www.ebi.ac.uk/chebi/about
- https://www.ebi.ac.uk/chebi/downloads

ChEBI publishes website data under CC BY 4.0. Good for chemical names, identifiers, definitions and ontology relationships. Preserve entity ID, exact source URL and attribution. A future one-time importer can select a small set of relevant entities and produce drafts; database descriptions still need AP-level rewriting and review.

## Chemical properties: PubChem

- https://pubchem.ncbi.nlm.nih.gov/docs/downloads

Useful for formulas, identifiers and structures. Check the underlying contributor and individual data license; PubChem explicitly warns that contributors can have different reuse terms. Do not blanket-label everything public domain.

## Molecular structures: PDB

- https://www.rcsb.org/pages/usage-policy

PDB archive data is CC0. Website articles and other text are separately copyrighted. Use archive coordinates for future molecular rendering with structure IDs and scientific citations; don't treat website screenshots or educational illustrations as automatically CC0.

## Diagrams

The current dataset intentionally has no images. Own drawings or per-file verified openly licensed Wikimedia assets are options. Record creator, source page, license, modifications and alt text for every asset before inclusion. No AI-generated scientific diagrams are needed.
